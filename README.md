# Algorithm Challenge #13 – Identity Matrix Check (Level 3)

🧮 Problem Description  
-
This C++ program checks whether a given 3×3 matrix is an **Identity Matrix**.

An Identity Matrix is defined by strict mathematical rules:
- All diagonal elements must be **1**
- All other elements must be **0**

---

💡 What You’ll Learn
-
- Matrix traversal using nested loops
- Identifying diagonal vs non-diagonal elements
- Translating mathematical definitions into code
- Writing precise conditional logic
- Ensuring correctness over assumptions

---

🧩 Example
-
Matrix:

1  0  0  
0  1  0  
0  0  1  

Output:

YES: Matrix is Identity.
